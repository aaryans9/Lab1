# Lab1

In the website, the first thing to do would be to register an account, then one can log in using that. There is also a logout option on the top right that can be used that any time. The books can be searched by its title, author or ISBN number. We can then go to the book's specific page from there, where it would have all the information about the book. Here, we can also give a written review for the book as well as give it a rating out of 5. The information regarding a book can also be accessed using the link 127.0.0.1:5000/api/'isbn of the book'.

The main file with most of the functions is app.py. In apiservice.py, there is a function that helps with getting all of the data from google api and import.py is used while trying to populate the database. In the templates folder, it contains all the html files for each specific page including register.html, login.html, books.html and others.
